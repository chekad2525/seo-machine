# گزارش ممیزی SEO پروژه SEO Machine

تاریخ ممیزی: ۲۰۲۶-۰۹-۱۵  
دامنه ممیزی: تمام مسیرهای وب موجود در سورس پروژه  
روش: بررسی سورس، build پروداکشن و کنترل پاسخ‌های HTTP روی سرور محلی

## جمع‌بندی اجرایی

تنها صفحه عمومی پروژه، صفحه اصلی (`/`) است و برای ایندکس شدن آماده شده است. مسیرهای ورود و داخل محصول (`/sign-in`، `/onboarding`، `/dashboard`، `/analytics` و `/keywords`) عنوان و توضیح اختصاصی دارند، اما عمداً از ایندکس خارج شده‌اند تا صفحات کم‌ارزش، خصوصی یا وابسته به حساب کاربری وارد نتایج جست‌وجو نشوند.

امتیاز موقت ممیزی سورس پس از اصلاحات: **۸۱ از ۱۰۰**. این امتیاز شامل داده میدانی Core Web Vitals، وضعیت واقعی ایندکس Google Search Console یا اعتبار دامنه نیست و نباید جایگزین ممیزی پس از انتشار شود.

## وضعیت مسیرها

| مسیر | هدف جست‌وجویی | وضعیت ایندکس | پیاده‌سازی |
| --- | --- | --- | --- |
| `/` | معرفی محصول و جذب کاربر | `index, follow` | title، description، canonical، hreflang فارسی، Open Graph، Twitter Card و JSON-LD |
| `/sign-in` | ورود/ثبت حساب | `noindex, follow` | متادیتای اختصاصی و X-Robots-Tag |
| `/onboarding` | راه‌اندازی حساب | `noindex, nofollow` | متادیتای اختصاصی و X-Robots-Tag |
| `/dashboard` | داشبورد خصوصی | `noindex, nofollow` | متادیتای اختصاصی و X-Robots-Tag |
| `/analytics` | تحلیل خصوصی | `noindex, nofollow` | متادیتای اختصاصی و X-Robots-Tag |
| `/keywords` | رهگیری خصوصی | `noindex, nofollow` | متادیتای اختصاصی و X-Robots-Tag |
| `/api/*` | API داخلی | `noindex, nofollow` | X-Robots-Tag و منع crawl در robots.txt |

## اصلاحات انجام‌شده

- متادیتای سراسری و منحصربه‌فرد هر صفحه با زبان `fa-IR` و جهت RTL اضافه شد.
- canonical صفحه اصلی از `APP_ORIGIN` ساخته می‌شود.
- `robots.txt` و `sitemap.xml` تولید می‌شوند؛ sitemap فقط صفحه عمومی و قابل‌ایندکس را شامل می‌شود.
- داده ساختاریافته معتبر و بدون ادعای تأییدنشده برای `Organization`، `WebSite` و `WebPage` اضافه شد.
- `llms.txt` با معرفی کوتاه، واقعی و قابل استناد محصول اضافه شد.
- محتوای صفحه اصلی با پاسخ مستقیم به «SEO Machine چیست؟»، شرح داده‌های ورودی، فرصت‌های قابل شناسایی و مدل دسترسی فقط‌خواندنی توسعه یافت.
- اعداد رابط نمایشی به‌وضوح با برچسب «نمونه» مشخص شدند و عبارت‌های تبلیغاتی اثبات‌نشده اصلاح شدند.
- فونت خارجی render-blocking حذف شد و حداقل اندازه CTA موبایل افزایش یافت.
- هدرهای `nosniff`، `DENY` و `strict-origin-when-cross-origin` اضافه شدند.

## شواهد فنی

- build پروداکشن: موفق؛ ۱۶ صفحه/مسیر تولید شد.
- typecheck تمام workspaceها: موفق.
- تست‌ها: ۹۰ تست API (۸۴ موفق، ۶ skip)، ۴ تست وب و ۲ تست دیتابیس؛ بدون failure.
- کنترل HTTP محلی: همه صفحات ممیزی‌شده و فایل‌های `robots.txt`، `sitemap.xml` و `llms.txt` پاسخ ۲۰۰ دادند.
- صفحه اصلی canonical و `index, follow` دارد؛ تمام مسیرهای خصوصی هم‌زمان meta robots و X-Robots-Tag مناسب دارند.

## محدودیت‌ها و ریسک‌های باقی‌مانده

- پیش از انتشار باید `APP_ORIGIN` و `NEXTAUTH_URL` روی URL نهایی HTTPS تنظیم شوند؛ خروجی محلی طبیعتاً `localhost` را نشان می‌دهد.
- Core Web Vitals، Lighthouse موبایل، crawl دامنه نهایی و رندر بصری مرورگر به URL منتشرشده نیاز دارند و در این ممیزی منبع‌محور اندازه‌گیری نشده‌اند.
- ایندکس واقعی، queryها، CTR و پوشش sitemap فقط پس از اتصال Google Search Console قابل تأیید است.
- پروژه هنوز صفحات عمومی اعتماد مانند «درباره ما»، «حریم خصوصی» و «تماس» ندارد. این صفحات تنها زمانی باید افزوده شوند که اطلاعات حقوقی و تماس واقعی آماده باشد.
- امتیاز فعلی موقت است و بعد از داده‌های میدانی باید دوباره محاسبه شود.
