# Search Data Pipeline — delivery slice

This slice extends the v0.4.0 identity, tenant, and Google Search Console foundation.

## Delivered

- Added a migration for `SearchConsoleSyncRun`, `SearchConsoleQueryMetric`, and `SearchConsolePageMetric`.
- Added tenant-scoped sync, metrics, and latest-run APIs.
- Added bounded date-range validation: one to 31 days.
- Added a default 28-day complete-data window ending two days before the current date.
- Added idempotent metric upserts keyed by connection, date, and dimension value.
- Added safe handling for expired Search Console authorization and failed runs.
- Added dashboard status and a first-sync action after a property is connected.
- Added unit coverage for date-window and metric-row normalization behavior.

## API examples

```text
POST /api/v1/integrations/google-search-console/sync
{ "projectId": "..." }

GET /api/v1/integrations/google-search-console/metrics?projectId=...&dimension=query&limit=100
GET /api/v1/integrations/google-search-console/sync/latest?projectId=...
```

All authenticated routes remain tenant-scoped through the membership boundary. The Next.js server signs API requests; a plain `x-user-id` is not accepted. See [internal authentication](internal-api-auth.md).
